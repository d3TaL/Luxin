# FixedBigMapPlan — стабильный трекинг большой карты с маркерами

## Проблема

При малейшем сдвиге большой карты сбивается опора (анкор) и запускается полный пересбор SIFT по всем эталонам. Причина: `BigMapSession::update` в `tracker/src/bigmap_session.cpp` уничтожает анкор при первом же `movement_px > 0.6` + appearance failure (`dense_change`/`tile_change`/`controls_change`). Следящий ORB не справляется сдвигом карты + изменением иконок/облаков/панели, сессия сбрасывается, и каждый кадр ищет заново. Эталонов мало (пара локаций), поэтому после сдвига за пределы покрытия follow не восстанавливается.

Дополнительно отсутствует:
- рендер маркеров grande карты на оверлее;
- фильтрация маркеров по'espace и этажу;
- определение этажа grande карты (сетка не должна меняться при переключении этажа);
- загрузка всех чанков Kongying (сейчас 2 из 46).

## Инварианты (не нарушать)

1. **Пространство ≠ Этаж ≠ Игрок.** `registerBigMap` даёт `space` + матрицу `T_K_to_F`. Этаж определяется отдельно по колонке кнопок. Центр grande карты ≠ игрок.
2. **Переключение этажа не меняет сетку.** Геометрия (`T_K_to_F`) остаётся прежней; меняется только набор отображаемых маркеров.
3. **При движении карты не сбрасывать анкор полностью.** Follow обновляет матрицу relative к анкору; сброс только при потере follow на нескольких кадрах подряд или при смене `space` / размера кадра / Stop.
4. **Fail closed.** При `rejected`/`ambiguous`/`moving` — скрыть все маркеры. Старая матрица не используется.
5. **Срок годности:** кадр ≤ 1 с, опора ≤ 10 с. При истечении — скрыть маркеры, не дрейфовать.

## Этапы реализации

### Этап 1 — Данные: все чанки маркеров + индекс по'espace/этажу (сейчас)

Загружать все 46 чанков маркеров Kongying (не только `firstOrNull` + `lastOrNull`). Сохранять `LocalMarkerRecord` с полями `space`, `levels`, `isUnderground`. Построить индекс `space → список маркеров`.

Файлы: `app/.../data/KongyingSyncManager.kt`, `app/.../data/KongyingModels.kt`

### Этап 2 — Стабильная сессия grande карты (не сбрасывать анкор при малом сдвиге)

В `BigMapSession` ввести разделение `geometry_anchor` (абсолютная привязка к эталону) и `track_anchor` (текущий кадр для follow). При успехе follow обновлять `track_anchor` и компенсировать матрицу; анкор уничтожать только после N неудачных follow подряд или при смене `space`/размера/Stop. При `moving` скрывать маркеры, но не сбрасывать сессию.

Файл: `tracker/src/bigmap_session.cpp`

### Этап 3 — Определение этажа grande карты (не меняет сетку)

Детектор колонки кнопок уровней справа: какая кнопка подсвечена (поверхность / уровень 1–3). Группа уровней по центру экрана. Перепроверка ярким фрагментом уровня через изображение уровня Kongying. Выход: `LayerDecision { layerId | surface | unknown }`. Unknown ≠ поверхность. При смене этажа не сбрасывать `BigMapSession`.

Файл: `app/.../tracker/BigMapLayerDetector.kt` (новый)

### Этап 4 — Фильтрация и подготовка маркеров grande карты

Фильтр: `marker.space == geometry.space`; этаж маркера совпадает с этажом grande карты (пустой уровень = поверхность); пользовательские настройки; маркер внутри кадра после проекции `toDisplay`. Кэш проекций — пересчитать только при смене матрицы или этажа.

Файл: `app/.../tracker/BigMapMarkerFilter.kt` (новый)

### Этап 5 — Отрисовка маркеров grande карты на Overlay

Полноэкранный слой `WindowManager` + `View` с `Canvas`. Проекция через `BigMapGeometry.toDisplay` → экранные px → Canvas dp. Иконки по `iconId` с асинхронной загрузкой. Скрытие при `screenMode != "big_map"`, `geometry == null`, фазе `moving`/`rejected`/`acquiring`, истечении срока (`stale`). При смене этажа — перерисовка того же Canvas с другим набором.

Файлы: `OverlayService.kt`, `BigMapMarkerOverlay.kt` (новый)

### Этап 6 — Связка в CaptureService

В фазе `tracking` публиковать `bigMapGeometry`; при `moving` очищать геометрию (маркеры скрыты), не сбрасывать сессию; при `rejected`/`ambiguous` — полный поиск через ≥ 2 с; при смене этажа не сбрасывать `BigMapSession`; при `Stop`/паузе/закрытии — `resetBigMap()`.

Файл: `CaptureService.kt`

### Этап 7 — Проверка

Десктоп: `ctest` (`test_bigmap_geometry`, `test_bigmap_session`) + новый тест: follow не сбрасывает анкор при малом сдвиге. Android только через CI (`./gradlew testDebugUnitTest assembleDebug`). Критерий: метки не исчезают при плавном сдвиге; при смене этажа сетка не пересчитывается; после остановки восстанавливаются без полной перепривязки.

## Приемка всего плана

На поддерживаемых эталонах: маркеры телепортов grande карты накладываются на игровые иконки в разных масштабах, со сдвигом, с открытой/закрытой панелью. При движении карты метки скрываются; после остановки и двух чистых проверок — восстанавливаются с новой матрицей. Устаревшие метки не остаются.
